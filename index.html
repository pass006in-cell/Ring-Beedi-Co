▸ Bulk Import

You can upload an Excel (.xlsx) file with any of these sheets (exact sheet names):
• Entries — Date, Day, Section, Number, Beedi, Advance, Patti, Others
• Expenses — Date, Type, Label, Amount (Type: StaffPayment/OtherDaily/NonDaily/Income)
• CompanyLedger — Date, OB, AdvanceCO, AdvanceSPSpl, SaleIncome, TotalIncome, Total, GrossWage, StaffTotal, OtherTotal, NonDailyTotal, PattiTotal, TotalExpense, OthersTotal, CB
• CashSummary — Date, Day, CashInHand, AdvanceCO, AdvanceSPSpl, TotalAvailable, GrossWage, StaffTotal, OtherTotal, PattiTotal, OthersTotal, TotalOutgo, BalCash
• Stock — Date, Item, Opening, Production, Sale, Short, Closing (Item: ORD or SPL)
• StockMovements — Date, Item, Type, Label, Amount (Item: ORD/SPL, Type: Sale/Short)
(Date format: YYYY-MM-DD on every sheet)
