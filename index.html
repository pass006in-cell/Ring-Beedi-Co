Bulk Import

ഒരു Excel (.xlsx) file-ൽ ഈ sheet-കൾ (ഏതെങ്കിലും ഉള്ളവ, exact sheet names) upload ചെയ്യാം:
• Entries — Date, Day, Section, Number, Beedi, Advance, Patti, Others
• Expenses — Date, Type, Label, Amount (Type: StaffPayment/OtherDaily/NonDaily/Income)
• CompanyLedger — Date, OB, AdvanceCO, AdvanceSPSpl, SaleIncome, TotalIncome, Total, GrossWage, StaffTotal, OtherTotal, NonDailyTotal, PattiTotal, TotalExpense, OthersTotal, CB
• CashSummary — Date, Day, CashInHand, AdvanceCO, AdvanceSPSpl, TotalAvailable, GrossWage, StaffTotal, OtherTotal, PattiTotal, OthersTotal, TotalOutgo, BalCash
(Date format: YYYY-MM-DD എല്ലാ sheet-ലും)

Backup / Restore

മൊത്തം data-യുടെ (Entries, Expenses, CompanyLedger, CashSummary, Stock, StockMovements, Workers) ഒരു full backup Excel file ആയി download ചെയ്യാം, വേണമെങ്കിൽ അതിൽ നിന്ന് തന്നെ തിരിച്ച് restore ചെയ്യാം.

Backup file-ൽ നിന്ന് Restore ചെയ്യുക

⚠️ Restore ചെയ്യുന്നത് നിലവിലെ data overwrite ചെയ്യും (backup file-ൽ ഉള്ള dates/records-ന്).

Delete Data (⚠️ Careful)
